系统说明

了解系统架构与技术细节

架构概览

本系统采用规则引擎 + LLM 大模型双轨审核架构。用户提交保险营销内容后，系统首先通过规则引擎进行关键词匹配和模式识别，随后调用大语言模型进行语义理解和深度分析，最终综合两路结果给出合规判定。

用户输入 → 规则引擎(关键词/模式) → LLM语义分析 → 结果融合 → 合规判定
                ↓                       ↓
          命中规则            语义违规
                ↓—————— 综合决策 ——————↓
              合规 / 违规 / 人工复核

技术栈

后端框架FastAPI (Python 3.11+)
大语言模型通义千问 (qwen-plus)
规则引擎自定义关键词 + 正则匹配
数据库SQLite / PostgreSQL
向量存储FAISS (法规检索)
前端原生 HTML/CSS/JS
认证API Key + JWT
部署Docker + Nginx

安全特性

  • API Key 认证机制，防止未授权访问
  • JWT Token 会话管理，支持过期刷新
  • 输入内容脱敏处理，不记录原始敏感数据
  • 审核日志完整记录，支持审计追溯
  • 人工复核操作留痕，确保可追溯性
  • 法规条款版本化管理，支持历史回溯
  • 模型调用频率限制，防止滥用
  • HTTPS 传输加密，保障数据安全
