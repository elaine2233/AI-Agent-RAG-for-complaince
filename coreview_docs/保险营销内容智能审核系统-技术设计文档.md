## 1. 项目概述

### 1.1 项目背景

金融行业对外营销内容（图文、短视频等）数量激增，传统人工审核面临三大痛点：

| 痛点 | 描述 |
|------|------|
| **效率低** | 人工审核单篇内容平均需15-30分钟，日均处理量有限 |
| **成本高** | 合规审核团队人力成本占营销运营成本的30%+ |
| **一致性差** | 不同审核人员对同一内容的判断存在主观差异 |

### 1.2 项目目标

构建基于阿里云百炼平台的**保险营销内容智能审核系统**，实现：

- **自动化审核**：输入文本/图文，自动输出合规判断、违规类型、引用条文、置信度
- **高准确率**：核心违规类型召回率 ≥ 95%，精确率 ≥ 90%
- **可解释性**：每条审核结论可追溯至具体法规条文
- **可扩展性**：支持新增法规、新增违规类型的灵活扩展

### 1.3 审核依据

本系统以三部核心监管文档作为审核知识库：

| 法规名称 | 发文单位 | 施行日期 |
|----------|----------|----------|
| 《保险销售行为管理办法》 | 国家金融监督管理总局 | 2024-03-01 |
| 《金融产品网络营销管理办法》 | 八部门联合公告 | 2026-09-30 |
| 《互联网保险业务监管办法》 | 银保监会 | 2021-02-01 |

### 1.4 输出格式规范

```json
{

  "content_type": "text",
  "is_compliant": false,
  "risk_level": "high",
  "confidence": 0.92,
  "violations": [
    {
      "violation_type": "夸大收益",
      "matched_text": "年化收益率高达15%，稳赚不赔",
      "rule_reference": {
        "regulation": "《金融产品网络营销管理办法》",
        "article": "第十条第（三）项",
        "original_text": "不得明示或暗示资产管理产品保本、承诺收益..."
      },
      "reasoning": "该表述使用'稳赚不赔'暗示保本承诺收益，违反禁止承诺收益条款",
      "confidence": 0.95

  }
```

## 2. 阿里云百炼平台能力全景

### 2.1 平台能力与本项目映射关系

本项目综合运用百炼平台的四大核心能力：**RAG知识库、Agent智能体、Workflow工作流、模型API**。

| 百炼能力 | 本项目应用 | 具体用途 |
|----------|-----------|----------|
| **知识库（RAG）** | 法规知识库 | 存储三部法规的结构化条款，支持混合检索（向量+关键词） |
| **Agent 2.0** | 多Agent审核引擎 | 分类Agent、检索Agent、判断Agent、汇总Agent协作审核 |
| **Workflow** | 审核流程编排 | 可视化编排预处理→分类→检索→判断→汇总→人工复核流程 |
| **模型API** | 核心推理引擎 | Qwen-Max/Plus/Turbo可配置切换，支持Function Calling和结构化输出 |
| **模型评测** | 效果评估 | 使用LLM-as-Judge + 规则评估进行多维度评测 |
| **内容安全** | 输入/输出护栏 | 百炼文本审核服务 + AI安全护栏服务 |
| **应用观测** | 可观测性 | OpenTelemetry集成，端到端请求链路追踪 |

### 2.2 模型选型策略

采用**多模型级联路由**策略，平衡效果与成本：

| 审核阶段 | 推荐模型 | 上下文窗口 | 选型理由 |
|----------|----------|-----------|----------|
| 预处理/分类 | `qwen-turbo` | 1M | 任务简单，追求低延迟低成本 |
| RAG检索+判断 | `qwen-plus` | 1M | 需要较强的理解和推理能力 |
| 终审裁决/汇总 | `qwen-max` | 256K | 复杂推理，追求最高准确率 |
| 评估Judge | `qwen-max` | 256K | 需要最强推理能力作为裁判 |

> 所有模型均支持 **Function Calling** 和 **结构化输出（JSON Mode）**，且可通过 `enable_thinking` 开启深度思考模式。

### 2.3 关键技术特性利用

| 特性 | 说明 | 本项目价值 |
|------|------|-----------|
| **1M超长上下文** | Qwen3.6-Plus/Flash支持100万Token | 可一次性输入整篇法规文档，无需分块 |
| **深度思考模式** | `enable_thinking` 参数开启 | 法规交叉引用、复杂逻辑推理场景 |
| **结构化输出** | `response_format: { type: "json_object" }` | 保证审核结果格式一致性 |
| **批量推理** | `qwen-plus`/`qwen-max`支持 | 历史内容批量回溯审核 |
| **知识库监控API** | 2026年1月新增 | 实时监控检索质量，动态优化知识库 |

### 4.1 审核工作流设计（Workflow）

基于百炼Workflow可视化编排，设计六阶段审核流水线：

```
[开始] → [内容预处理] → [意图分类] → [条件分支]
                                        │
                    ┌───────────────────┼───────────────────┐
                    ▼                   ▼                   ▼
              [快速通道]          [标准审核通道]         [深度审核通道]
              (低风险)           (中风险)             (高风险/复杂)
                    │                   │                   │
                    │           ┌───────┴───────┐           │
                    │           ▼               ▼           │
                    │     [RAG法规检索]   [多模态解析]       │
                    │           │               │           │
                    │           ▼               ▼           │
                    │     [多维审核Agent] [图文交叉审核]     │
                    │           │               │           │
                    └───────────┼───────────────┘───────────┘
                                ▼
                        [交叉验证Agent]
                                ▼
                        [风险评分汇总]
                                ▼
                        [条件分支]
                        │         │
                  (自动通过)  (人工复核队列)
                        │         │
                        ▼         ▼
                      [结束]   [人工审核→结束]
```

**百炼Workflow节点配置**：

| 节点类型 | 百炼节点 | 配置要点 |
|----------|----------|----------|
| 内容预处理 | 大模型节点 | 使用qwen-turbo，关闭思考模式，JSON输出 |
| 意图分类 | 意图分类节点 | 多选模式：保险/理财/贷款/其他 |
| 条件分支 | 条件判断节点 | 基于风险等级字段路由 |
| RAG检索 | 知识库节点 | 智能调用模式，TopK=5，相似度阈值0.6 |
| 多维审核 | 智能体群组节点 | 分类Agent+审核Agent并行 |
| 交叉验证 | 大模型节点 | 使用qwen-max，开启思考模式 |
| 风险评分 | 脚本节点 | Python脚本计算综合风险分 |
| 人工复核 | API节点 | 调用外部审批系统Webhook |

### 4.2 多Agent协作设计（Agent）

采用**百炼Agent 2.0**的自主规划调度能力，设计四个专业化Agent：

#### Agent 1：分类Agent（Classifier Agent）

```yaml
Agent名称: 内容分类专家
模型: qwen-turbo
思考模式: 关闭
职责:
  - 识别营销内容的类型（文字/图文/短视频脚本）
  - 判断涉及的金融产品类别（保险/理财/贷款）
  - 初步评估风险等级（高/中/低）
  - 提取关键审核维度（收益表述/资质/风险提示等）
系统提示词: |
  你是一位金融营销内容分类专家。请对输入的营销内容进行分类分析：
  1. 内容类型识别
  2. 产品类别判断
  3. 风险等级初判
  4. 关键审核维度提取
  输出JSON格式。
工具: 无
记忆: 0轮（无状态）
```

#### Agent 2：检索Agent（Retrieval Agent）

```yaml
Agent名称: 法规检索专家
模型: qwen-plus
思考模式: 关闭
职责:
  - 基于分类结果构建检索Query
  - 调用百炼知识库进行法规检索
  - 对检索结果进行相关性排序和过滤
  - 组装审核上下文
工具:
  - 百炼知识库（标签过滤：按法规名称和违规类型）
  - 联网搜索（补充最新监管动态）
系统提示词: |
  你是一位金融法规检索专家。基于营销内容的分类结果，
  构建精准的检索Query，从法规知识库中检索最相关的条款。
  检索策略：
  1. 语义检索：基于内容含义匹配相关条款
  2. 关键词检索：匹配禁止性用语和关键表述
  3. 交叉引用：检索多个法规中的关联条款
  返回Top-5最相关条款及其原文。
记忆: 0轮（无状态）
```

#### Agent 3：审核Agent（Audit Agent）

```yaml
Agent名称: 合规审核专家
模型: qwen-max
思考模式: 开启（思考长度: 8000 token）
职责:
  - 逐条分析营销内容是否违反检索到的法规条款
  - 识别具体违规类型和违规文本片段
  - 引用具体条文编号和原文
  - 给出每条违规的置信度评分
  - 生成违规理由和修改建议
工具:
  - 百炼知识库（补充检索）
系统提示词: |
  你是一位资深金融合规审核专家，精通保险行业监管法规。

  ## 审核原则
  1. 严格性：宁可误报不可漏报，对疑似违规内容给出低置信度标记
  2. 精准性：每条违规必须引用具体条文编号和原文
  3. 完整性：覆盖所有可能涉及的违规维度
  4. 可解释性：清晰说明违规推理过程

  ## 审核维度
  - 夸大收益/夸大宣传
  - 虚假宣传/不实陈述
  - 承诺收益/保本宣传
  - 缺少风险提示
  - 误导性表述
  - 无资质经营/代言
```

```python
# core/workflow.py
"""审核工作流 - 基于百炼DashScope API实现"""

import json
import time
import logging
from typing import Optional
from openai import OpenAI
from core.models.schemas import (
    AuditRequest, AuditResult, ClassificationResult,
    Violation, RuleReference, RiskLevel, ViolationType
)
from config.settings import settings
from core.rag.knowledge_base import KnowledgeBaseRetriever
from core.agents.classifier import ClassifierAgent
from core.agents.auditor import AuditAgent
from core.agents.summarizer import SummarizerAgent

logger = logging.getLogger(__name__)


class AuditWorkflow:
    """
    保险营销内容智能审核工作流

    流程: 预处理 → 分类 → RAG检索 → 多维审核 → 交叉验证 → 汇总裁决
    """

    def __init__(self):
        self.client = OpenAI(
            api_key=settings.DASHSCOPE_API_KEY,
            base_url=settings.DASHSCOPE_BASE_URL,
        )
        self.retriever = KnowledgeBaseRetriever()
        self.classifier = ClassifierAgent(self.client)
        self.auditor = AuditAgent(self.client)
        self.summarizer = SummarizerAgent(self.client)

    def audit(self, request: AuditRequest) -> AuditResult:
        """
        执行完整审核流程

        Args:
            request: 审核请求

        Returns:
            AuditResult: 审核结果
        """
        start_time = time.time()
        audit_id = f"AUD-{time.strftime('%Y%m%d')}-{uuid.uuid4().hex[:6]}"

        logger.info(f"[{audit_id}] 开始审核, 内容类型: {request.content_type}")

        # === Step 1: 内容分类 ===
        classification = self.classifier.classify(request.content)
        logger.info(f"[{audit_id}] 分类结果: {classification.model_dump_json(indent=2)}")

        # === Step 2: RAG法规检索 ===
        retrieval_results = self.retriever.retrieve(
            query=request.content,
            filters={
                "violation_types": classification.risk_dimensions,
            },
            top_k=settings.RETRIEVAL_TOP_K,
        )
        logger.info(f"[{audit_id}] 检索到 {len(retrieval_results)} 条相关法规")

        # === Step 3: 多维审核 ===
        audit_result = self.auditor.audit(
            content=request.content,
            classification=classification,
            retrieved_rules=retrieval_results,
        )
        logger.info(f"[{audit_id}] 审核发现 {len(audit_result.violations)} 条违规")

        # === Step 4: 交叉验证 + 汇总裁决 ===
        final_result = self.summarizer.summarize(
            content=request.content,
            classification=classification,
            audit_result=audit_result,
            retrieved_rules=retrieval_results,
        )

        # === 组装最终结果 ===
        latency_ms = int((time.time() - start_time) * 1000)

        result = AuditResult(
            audit_id=audit_id,
            content_type=request.content_type,
            is_compliant=final_result.is_compliant,
            risk_level=final_result.risk_level,
            risk_score=final_result.risk_score,
            confidence=final_result.confidence,
            violations=final_result.violations,
            audit_metadata={
                "model": settings.AUDITOR_MODEL,
                "classification": classification.model_dump(),
                "rag_source_count": len(retrieval_results),
                "rag_sources": [r.get("chunk_id") for r in retrieval_results],
                "latency_ms": latency_ms,
                "timestamp": time.strftime("%Y-%m-%dT%H:%M:%S+08:00"),
            }
        )

        logger.info(
            f"[{audit_id}] 审核完成: "
            f"合规={result.is_compliant}, "
            f"风险等级={result.risk_level}, "
            f"风险评分={result.risk_score}, "
            f"置信度={result.confidence}, "
            f"违规数={len(result.violations)}, "
            f"耗时={latency_ms}ms"
        )

        return result
```

### 6.5 RAG检索实现

```python
# core/rag/knowledge_base.py
"""百炼知识库检索 - 基于DashScope API"""

import json
import logging
from typing import Optional
from openai import OpenAI
from config.settings import settings

logger = logging.getLogger(__name__)


class KnowledgeBaseRetriever:
    """
    百炼知识库检索器

    使用百炼Retrieve API进行混合检索（向量+关键词），
    支持多知识库权重、Meta信息过滤、相似度阈值。
    """

    def __init__(self):
        self.client = OpenAI(
            api_key=settings.DASHSCOPE_API_KEY,
            base_url=settings.DASHSCOPE_BASE_URL,
        )

    def retrieve(
        self,
        query: str,
        filters: Optional[dict] = None,
        top_k: int = 5,
        similarity_threshold: float = 0.6,
    ) -> list[dict]:
        """
        从百炼知识库检索相关法规条款

        Args:
            query: 检索查询文本
            filters: 过滤条件（违规类型标签等）
            top_k: 最大返回数量
            similarity_threshold: 相似度阈值

        Returns:
            检索结果列表，每个结果包含条文原文和元数据
        """
        all_results = []

        for kb_id in settings.KNOWLEDGE_BASE_IDS:
            try:
                # 构建检索请求
                request_body = {
                    "model": settings.EMBEDDING_MODEL,
                    "input": {
                        "query": query,
                        "knowledge_base_ids": [kb_id],
                        "top_k": top_k,
                        "similarity_threshold": similarity_threshold,
                    }
                }

                # 添加Meta过滤条件
                if filters and "violation_types" in filters:
                    request_body["input"]["metadata_filter"] = {
                        "key": "violation_types",
                        "value": filters["violation_types"],
                        "operator": "contains_any"
                    }

                # 调用百炼Retrieve API
                response = self.client.chat.completions.create(
                    model="retrieve",  # 百炼内置检索模型
                    messages=[{"role": "user", "content": json.dumps(request_body)}],
                )

                results = json.loads(response.choices[0].message.content)
                all_results.extend(results.get("retrieved_chunks", []))

                logger.info(f"知识库 {kb_id} 检索到 {len(results.get('retrieved_chunks', []))} 条结果")

            except Exception as e:
                logger.error(f"知识库 {kb_id} 检索失败: {str(e)}")
                continue

        # 按相似度排序并去重
        all_results.sort(key=lambda x: x.get("score", 0), reverse=True)

        # 去重（同一条文只保留最高分）
        seen_articles = set()
        unique_results = []
        for r in all_results:
            article_key = f"{r.get('regulation')}_{r.get('article')}"
            if article_key not in seen_articles:
                seen_articles.add(article_key)
                unique_results.append(r)

        return unique_results[:top_k]
```

### 6.6 审核Agent实现

```python
# core/agents/auditor.py
"""审核Agent - 基于百炼Agent 2.0 + RAG"""

import json
import logging
from typing import Optional
from openai import OpenAI
from config.settings import settings
from config.prompts import AUDIT_SYSTEM_PROMPT
from core.models.schemas import (
    ClassificationResult, AuditResult, Violation,
    RuleReference, RiskLevel
)

logger = logging.getLogger(__name__)


class AuditAgent:
    """
    合规审核Agent

    基于百炼Agent 2.0的自主规划能力，
    结合RAG检索到的法规条款进行多维合规审核。
    """

    def __init__(self, client: OpenAI):
        self.client = client
        self.model = settings.AUDITOR_MODEL

    def audit(
        self,
        content: str,
        classification: ClassificationResult,
        retrieved_rules: list[dict],
    ) -> AuditResult:
        """
        执行合规审核

        Args:
            content: 待审核内容
            classification: 分类结果
            retrieved_rules: RAG检索到的法规条款

        Returns:
            AuditResult: 审核结果
        """
        # 构建审核上下文
        rules_context = self._build_rules_context(retrieved_rules)

        # 构建用户消息
        user_message = f"""## 待审核内容
{content}

## 内容分类
- 产品类型: {classification.product_type}
- 内容类别: {classification.content_category}
- 需审核维度: {', '.join(classification.risk_dimensions)}
- 初判风险等级: {classification.initial_risk_level}

## 检索到的相关法规条款
{rules_context}

请基于以上法规条款，对该营销内容进行全面的合规性审核。"""

        # 调用百炼模型API（启用思考模式 + 结构化输出）
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[
                {"role": "system", "content": AUDIT_SYSTEM_PROMPT},
                {"role": "user", "content": user_message},
            ],
            response_format={"type": "json_object"},
            extra_body={
                "enable_thinking": settings.ENABLE_THINKING,
                "thinking_budget": settings.THINKING_BUDGET,
            },
            temperature=0.1,  # 低温度保证一致性
        )

        # 解析审核结果
        result_text = response.choices[0].message.content
        result_data = json.loads(result_text)

        # 转换为结构化结果
        violations = []
        for v in result_data.get("violations", []):
            violations.append(Violation(
                violation_type=v["violation_type"],
                matched_text=v["matched_text"],
                rule_reference=RuleReference(
                    regulation=v["rule_reference"]["regulation"],
                    article=v["rule_reference"]["article"],
                    original_text=v["rule_reference"]["original_text"],
                ),
                reasoning=v["reasoning"],
                confidence=v["confidence"],
                suggestion=v.get("suggestion"),
            ))

        return AuditResult(
            is_compliant=result_data.get("is_compliant", True),
            risk_level=RiskLevel(result_data.get("risk_level", "low")),
            risk_score=self._calculate_risk_score(violations),
            confidence=result_data.get("confidence", 0.5),
            violations=violations,
        )

    def _build_rules_context(self, retrieved_rules: list[dict]) -> str:
        """构建法规条款上下文"""
        context_parts = []
        for i, rule in enumerate(retrieved_rules, 1):
            context_parts.append(
                f"### 条款{i}: {rule.get('regulation', '未知法规')} - {rule.get('article', '')}\n"
                f"**原文**: {rule.get('original_text', '')}\n"
                f"**违规类型**: {', '.join(rule.get('violation_types', []))}\n"
                f"**相似度**: {rule.get('score', 0):.2f}"
            )
        return "\n\n".join(context_parts)

    def _calculate_risk_score(self, violations: list[Violation]) -> float:
        """
        计算风险评分（0-100）

        算法: 基于违规类型权重 + 置信度的加权评分
        """
        if not violations:
            return 0.0

        # 违规类型严重度权重
        severity_weights = {
            "夸大收益/夸大宣传": 0.9,
            "虚假宣传/不实陈述": 0.95,
            "承诺收益/保本宣传": 0.9,
            "缺少风险提示": 0.6,
            "误导性表述": 0.7,
            "无资质经营/代言": 0.85,
            "冒用监管信用": 0.95,
            "强制搭售/默认勾选": 0.7,
            "隐瞒保险属性/不当类比": 0.8,
            "诱导性用语": 0.5,
            "未充分提示免责条款": 0.6,
            "骚扰营销": 0.4,
            "阻碍退保": 0.7,
            "代签名/代确认": 0.8,
            "可回溯管理缺失": 0.5,
            "资金违规经手": 0.85,
            "不适当销售": 0.7,
        }

        max_score = 0.0
        for v in violations:
            weight = severity_weights.get(v.violation_type, 0.7)
            score = weight * v.confidence * 100
            max_score = max(max_score, score)

        return round(min(max_score, 100.0), 1)
```

### 7.2 评估指标定义

| 指标 | 定义 | 目标值 | 计算方式 |
|------|------|--------|----------|
| **Precision（精确率）** | 判定违规中真正违规的比例 | ≥ 90% | TP / (TP + FP) |
| **Recall（召回率）** | 真正违规中被成功识别的比例 | ≥ 95% | TP / (TP + FN) |
| **F1-Score** | 精确率和召回率的调和平均 | ≥ 92% | 2×P×R / (P+R) |
| **误拦截率（FPR）** | 合规内容被错误拦截的比例 | < 5% | FP / (FP + TN) |
| **条文引用准确率** | 引用的条文与实际违规的匹配度 | ≥ 95% | 正确引用数 / 总引用数 |
| **置信度校准** | 预测置信度与实际准确率的偏差 | < 10% | ECE (Expected Calibration Error) |

### 7.3 LLM-as-Judge评估实现

```python
# evaluation/evaluator.py
"""效果评估引擎 - LLM-as-Judge + 规则评估"""

import json
import logging
from typing import Optional
from openai import OpenAI
from config.settings import settings

logger = logging.getLogger(__name__)


class AuditEvaluator:
    """
    审核系统效果评估器

    使用两种评估方式：
    1. LLM-as-Judge: 使用qwen-max作为裁判评估审核质量
    2. 规则评估: 基于预定义规则的自动化评估
    """

    def __init__(self):
        self.client = OpenAI(
            api_key=settings.DASHSCOPE_API_KEY,
            base_url=settings.DASHSCOPE_BASE_URL,
        )
        self.judge_model = settings.EVAL_JUDGE_MODEL

    def evaluate_single(
        self,
        test_case: dict,
        audit_result: dict,
    ) -> dict:
        """
        评估单条审核结果

        Args:
            test_case: 测试用例（含标准答案）
            audit_result: 系统审核结果

        Returns:
            评估结果
        """
        # === LLM-as-Judge 评估 ===
        judge_result = self._llm_judge(test_case, audit_result)

        # === 规则评估 ===
        rule_result = self._rule_evaluate(test_case, audit_result)

        return {
            "test_case_id": test_case["id"],
            "llm_judge": judge_result,
            "rule_evaluation": rule_result,
            "final_verdict": self._aggregate(judge_result, rule_result),
        }

    def _llm_judge(self, test_case: dict, audit_result: dict) -> dict:
        """LLM-as-Judge评估"""
        judge_prompt = f"""你是一位资深金融合规审核质量评估专家。请评估以下审核结果的质量。

## 待审核内容
{test_case['content']}

## 标准答案（人工标注）
{json.dumps(test_case['expected'], ensure_ascii=False, indent=2)}

## 系统审核结果
{json.dumps(audit_result, ensure_ascii=False, indent=2)}

## 评估维度（每项1-5分）
1. **准确性**: 审核结论是否与标准答案一致
2. **完整性**: 是否遗漏了标准答案中的违规项
3. **精确性**: 是否存在误报（将合规内容判为违规）
4. **引用质量**: 引用的法规条文是否准确、相关
5. **推理质量**: 违规推理说明是否合理、有说服力

请以JSON格式输出评估结果：
{{
  "accuracy_score": 5,
  "completeness_score": 4,
  "precision_score": 5,
  "citation_score": 4,
  "reasoning_score": 4,
  "overall_score": 4.4,
  "analysis": "详细分析...",
  "improvement_suggestions": ["建议1", "建议2"]
}}"""

        response = self.client.chat.completions.create(
            model=self.judge_model,
            messages=[{"role": "user", "content": judge_prompt}],
            response_format={"type": "json_object"},
            temperature=0.1,
        )

        return json.loads(response.choices[0].message.content)

    def _rule_evaluate(self, test_case: dict, audit_result: dict) -> dict:
        """规则评估"""
        expected = test_case["expected"]
        actual = audit_result

        # 合规性判断是否正确
        is_compliant_correct = expected["is_compliant"] == actual.get("is_compliant")

        # 违规类型匹配
        expected_types = set(expected.get("violation_types", []))
        actual_types = set(v["violation_type"] for v in actual.get("violations", []))

        tp = len(expected_types & actual_types)  # 正确识别
        fp = len(actual_types - expected_types)   # 误报
        fn = len(expected_types - actual_types)   # 漏报

        precision = tp / (tp + fp) if (tp + fp) > 0 else 1.0
        recall = tp / (tp + fn) if (tp + fn) > 0 else 1.0
        f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0.0

        return {
            "is_compliant_correct": is_compliant_correct,
            "true_positives": tp,
            "false_positives": fp,
            "false_negatives": fn,
            "precision": round(precision, 4),
            "recall": round(recall, 4),
            "f1_score": round(f1, 4),
        }

    def evaluate_batch(
        self,
        test_cases: list[dict],
        audit_results: list[dict],
    ) -> dict:
        """
        批量评估

        Returns:
            综合评估报告
        """
        total_tp, total_fp, total_fn = 0, 0, 0
        judge_scores = []
        detailed_results = []

        for tc, ar in zip(test_cases, audit_results):
            result = self.evaluate_single(tc, ar)
            detailed_results.append(result)

            rule_eval = result["rule_evaluation"]
            total_tp += rule_eval["true_positives"]
            total_fp += rule_eval["false_positives"]
            total_fn += rule_eval["false_negatives"]

            if result["llm_judge"]:
                judge_scores.append(result["llm_judge"]["overall_score"])

        # 计算汇总指标
        precision = total_tp / (total_tp + total_fp) if (total_tp + total_fp) > 0 else 1.0
        recall = total_tp / (total_tp + total_fn) if (total_tp + total_fn) > 0 else 1.0
        f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0.0

        return {
            "summary": {
                "total_cases": len(test_cases),
                "overall_precision": round(precision, 4),
                "overall_recall": round(recall, 4),
                "overall_f1": round(f1, 4),
                "avg_judge_score": round(sum(judge_scores) / len(judge_scores), 2) if judge_scores else 0,
                "total_true_positives": total_tp,
                "total_false_positives": total_fp,
                "total_false_negatives": total_fn,
            },
            "detailed_results": detailed_results,
            "recommendations": self._generate_recommendations(precision, recall, f1),
        }

    def _generate_recommendations(self, precision: float, recall: float, f1: float) -> list[str]:
        """生成改进建议"""
        recommendations = []
        if recall < 0.90:
            recommendations.append(
                "召回率偏低，建议：1) 扩充知识库中的同义词和变体表述；"
                "2) 增加FewShot样例覆盖更多违规模式；"
                "3) 调低RAG检索的相似度阈值"
            )
        if precision < 0.85:
            recommendations.append(
                "精确率偏低，建议：1) 提高审核Agent的置信度阈值；"
                "2) 优化Prompt中的审核原则，减少过度敏感；"
                "3) 增加交叉验证环节"
            )
        if f1 >= 0.92:
            recommendations.append("系统整体表现优秀，建议持续积累审核判例并定期更新知识库")
        return recommendations
```

```python
# api/middleware/rate_limit.py
"""限流熔断中间件"""

import time
from collections import defaultdict
from threading import Lock


class RateLimiter:
    """
    令牌桶限流器

    支持多维度限流：per-API-Key、per-IP、全局
    """

    def __init__(
        self,
        rate_per_minute: int = 60,
        burst: int = 10,
    ):
        self.rate = rate_per_minute
        self.burst = burst
        self.tokens = defaultdict(float)
        self.last_update = defaultdict(float)
        self.lock = Lock()

    def allow(self, key: str) -> bool:
        """检查是否允许请求"""
        with self.lock:
            now = time.time()
            elapsed = now - self.last_update[key]
            self.tokens[key] = min(
                self.burst,
                self.tokens[key] + elapsed * (self.rate / 60.0)
            )
            self.last_update[key] = now

            if self.tokens[key] >= 1.0:
                self.tokens[key] -= 1.0
                return True
            return False


class CircuitBreaker:
    """
    熔断器

    三种状态：CLOSED（正常）→ OPEN（熔断）→ HALF_OPEN（试探恢复）
    """

    def __init__(
        self,
        failure_threshold: int = 5,
        recovery_timeout: int = 300,
        half_open_max_calls: int = 3,
    ):
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.half_open_max_calls = half_open_max_calls
        self.failure_count = 0
        self.state = "CLOSED"
        self.last_failure_time = 0
        self.half_open_calls = 0

    def allow(self) -> bool:
        if self.state == "CLOSED":
            return True
        elif self.state == "OPEN":
            if time.time() - self.last_failure_time > self.recovery_timeout:
                self.state = "HALF_OPEN"
                self.half_open_calls = 0
                return True
            return False
        else:  # HALF_OPEN
            if self.half_open_calls < self.half_open_max_calls:
                self.half_open_calls += 1
                return True
            return False

    def record_success(self):
        if self.state == "HALF_OPEN":
            self.state = "CLOSED"
            self.failure_count = 0

    def record_failure(self):
        self.failure_count += 1
        self.last_failure_time = time.time()
        if self.state == "HALF_OPEN" or self.failure_count >= self.failure_threshold:
            self.state = "OPEN"
```

### 10.2 关键条文原文摘录

**《金融产品网络营销管理办法》第十条（核心禁止性条款）**：

> 网络营销内容不得有下列情形：
> （一）使用虚假或者引人误解的内容；
> （二）引用不真实、不准确或未经核实的数据和资料；
> （三）明示或暗示资产管理产品、投资顾问或者咨询服务保本、承诺收益、限定损失金额或比例，简单依据短期、非常态的业绩比较基准或者过往业绩高低进行展示排序，预测未来业绩，或者利用模拟业绩、部分客户或者个别有利时段的表现等方式误导投资者；
> （四）夸大保险责任或保险产品收益，将保险产品收益与存款、资产管理产品等金融产品简单类比；
> （五）利用金融管理部门、行业自律组织对金融产品的审核或备案程序，误导金融消费者和投资者认为金融管理部门、行业自律组织对该金融产品提供保证；
> （六）涉及分期付款的，通过片面宣传首期费用优惠等方式诱导消费；
> （七）使用"低风险""低门槛""秒到账""高收益""低利率""无成本"等诱导性用语。

**《保险销售行为管理办法》第十七条第（三）项**：

> 不得引用不真实、不准确的数据和资料，不得隐瞒限制条件，不得进行虚假或者夸大表述，不得使用偷换概念、不当类比、隐去假设等不当宣传手段。

**《互联网保险业务监管办法》第十五条第（四）项**：

> 不得进行不实陈述或误导性描述，不得片面比较保险产品价格和简单排名，不得与其他非保险产品和服务混淆，不得片面或夸大宣传，不得违规承诺收益或承诺承担损失。
