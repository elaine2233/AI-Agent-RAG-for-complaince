01

项目背景

监管要求严格

  • 《保险销售行为管理办法》
  • 《互联网保险业务监管办法》
  • 《金融产品网络营销管理办法》

禁止绝对化用语、承诺收益、夸大收益、无资质代言……

人工审核困境

❌ 效率低 — 日均数百条，逐条人工审

❌ 标准不统一 — 同一内容不同审核员结论不同

❌ 易漏审 — 语义隐含违规肉眼难发现

❌ 法规更新 — 新规出台后标准需同步

目标：自动判断营销内容是否违规 → 违规类型 + 法规依据 + 风险评分

02

三个核心设计约束

约束1 零漏判

一条违规漏过去 = 监管处罚

宁可误报不可漏报，但误报太多人工复核成本爆炸

约束2 法规有隐含逻辑

"禁止 + 例外" 向量检索无法捕捉

传统 RAG 只做语义检索会断章取义

约束3 Demo/生产双场景

同一套代码：30秒启动 vs 99.9%可用性

接口隔离，换实现不改逻辑

03

② 规则预检 Rule Check

Rule + LLM 协同 — 系统第一个亮点

关键词库快速预筛查：

  • "稳赚不赔" → 命中 绝对化用语
  • "年化收益" → 命中 夸大收益

关键决策：规则命中 ≠ 跳过LLM

规则命中后，结果注入 LLM Prompt

"已发现关键词违规，请继续检查更深层问题"

为什么不跳过？"未来稳稳的幸福" — 没触发任何关键词，但保险语境下构成对确定性的暗示

03

③ RAG 检索 + ④ 重排序

③ RAG 检索
  • ChromaDB 向量检索，HNSW 索引
  • 嵌入：text-embedding-v3，1024维
  • 召回 Top-20 条相关法规

🏗️ 生产：向量 + BM25 多路召回 + Query Rewriting

④ 重排序 Rerank
  • 有Key：qwen3-rerank Cross-Encoder → Top-5
  • 无Key：降级规则重排（字符重叠+关键词加权）
  • 相邻条文召回：Top-5每条自动召回前后条文，0.7折扣

为什么？一条条文的意思可能依赖上下文定义条款

03

⑤ 条款关联扩展

系统创新点 — 解决传统 RAG 断章取义问题

法规条文间 9 种关系类型：

关系示例
引用"依照第X条"
例外"除……外"
补充"前款所称……是指"
定义"本法下列用语的含义"

案例：第十九条"调整价格应公告"

+ 但书"费率浮动区间内除外"

→ 不追踪例外 = 所有调价都判违规

Demo：正则自动提取 + 49条预标注

生产：LLM 驱动法规知识图谱

03

⑦ Format + ⑧ Validate

⑦ 结构化归一化
  • 归一化：各种格式 → 标准 violations 数组
  • 规则参考注入：LLM未提 → reasoning前缀 [规则引擎参考命中]
  • 降级兜底：LLM失败+规则命中 → 规则引擎结果
  • 数据清洗：compliant→yes/no, confidence→0~1
⑧ 幻觉检测

LLM 可能编造不存在的法规条文

找到 → 保留

找不到 + 规则有命中 → 降级规则条文，置信度≤0.7

找不到 + 规则也没命中 → 违规降级"未知"，置信度≤0.4

03

⑨ 交叉复核 CrossCheck

独立轻量模型对审核结论做复核：

  • 引用条文与输入内容的语义相关性
  • 推理逻辑的自洽性
  • 输出：passed / issues / confidence_adjustment(±0.1)

冲突裁决机制：

主模型复核决策
违规合规保留主模型，降低置信度
合规违规降级为人工复核

成本仅增 20%，降低约 30% 漏判

03

⑩ 风险评估 Risk Assess

公式：severity×0.5 + article_count×0.1(max0.3) + rule_hit×0.15 + confidence_adj

< 0.15

低风险

auto_pass

0.15~0.70

中风险

human_review

≥ 0.70

高/严重

auto_block

案例结果："稳赚不赔，年化5%" → 风险分 1.0，Critical，auto_block

违规：收益承诺 + 绝对化用语 + 隐瞒信息 + 诱导销售

08

五个关键设计决策

1

Rule + LLM 协同，而非 Rule-First 跳过 LLM

纯规则无法检测语义隐含违规，纯LLM丢掉关键词确定性优势

2

10 步流水线，而非一个大 Prompt 端到端

端到端出了问题无法定位，无法局部降级；流水线每步可观测、可调试、可独立优化

3

轻量模型做 CrossCheck

成本仅增20%，降低30%漏判；金融场景一次漏判代价 >> 20% API费用

4

条款关系图，解决"禁止+例外"逻辑

向量相似度再高，也理解不了"但……除外"是对前半句的否定

5

Demo/生产分离，接口隔离

四个核心接口，换实现不改逻辑；Demo 30秒启动，生产99.9%可用
